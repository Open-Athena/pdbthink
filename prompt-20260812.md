# **Protein Structural Reasoning Benchmark**

## **Implementation specification**

This document is the implementation brief for a coding agent. Build a reproducible, single-turn benchmark that evaluates how well language models parse and reason about protein structures without tools or internet access during inference.

The benchmark should be implemented in [Evalchemy](https://github.com/marin-community/evalchemy), use deterministic task-specific scoring, provide a curator-facing review interface, and support inexpensive local iteration before frontier-model evaluation.

## **1\. Objective**

The benchmark should measure several separable capabilities:

1. Parsing realistic structural files.  
2. Performing elementary three-dimensional geometry.  
3. Translating geometry into structural-biology concepts.  
4. Reasoning across interfaces and residue-contact networks.  
5. Comparing two structural states.  
6. Connecting local structural changes to mechanistic consequences.

The evaluation protocol is inspired by [PG-LLM](https://www.biorxiv.org/content/10.64898/2026.07.27.741045v2): each item is a single model turn, and the evaluated model has no tools and no internet access.

### **V1 targets**

* A target of 97 semantic instances: 91 automatically generated instances across 19 question types, plus six composite mechanistic episodes.  
* A final acceptable range of 90-110 instances after curator rejection and replacement.  
* Several proteins per automatically generated question family.  
* Six manually curated mechanistic episodes.  
* Mostly short-answer questions, with multiple choice where a categorical mechanistic answer is more defensible.  
* Deterministic grading without an LLM judge.  
* Evaluation at multiple supported reasoning-effort levels.  
* Repeated completions and rotation controls to quantify variability.  
* Structures drawn only from the PDB or AlphaFold Database.

A **semantic instance** is one underlying scientific prompt. It may contain multiple deterministically scored fields, as in a mechanistic episode. Representation variants, alternate rotations, and repeated stochastic completions are linked evaluations of the same semantic instance and should not be counted as new semantic instances.

### **Non-goals for V1**

* Tool-using or agentic structural analysis.  
* Structure prediction from sequence.  
* Direct hydrogen-bond identification unless donor/acceptor chemistry is explicitly represented.  
* Reasoning over NMR ensembles or crystallographic alternate-conformer ensembles.  
* General mmCIF parsing. The implementation should be internally compatible with mmCIF input, but the primary model-visible file representation is minimal PDB.  
* Unconstrained LLM-judge grading.

## **2\. Scientific positioning**

Relevant prior work includes:

* [PG-LLM: Benchmarking General-Purpose Language Models for Protein Variant Ranking](https://www.biorxiv.org/content/10.64898/2026.07.27.741045v2)  
* [LiveProteinBench](https://arxiv.org/abs/2512.22257)  
* [ProtStructQA](https://arxiv.org/abs/2606.00451)

ProtStructQA is the closest structural-QA benchmark, but it maps language to hidden executable queries over AlphaFold structures. The present benchmark instead exposes atomic coordinates directly and tests tool-free parsing and coordinate reasoning.

## **6\. Representations and experimental controls**

### **Primary representation: minimal PDB**

The primary model-visible representation is a sanitized PDB containing only the coordinate records required by the task. Detailed processing rules are in Appendix A.

### **Simplified coordinate representation**

For a matched subset, render the same atoms as:

```
record,chain,resnum,resname,atom,element,x,y,z
ATOM,A,57,LYS,N,N,12.481,-3.117,8.226
...
```

The minimal-PDB and normalized-coordinate variants must contain equivalent atoms, coordinates, residue labels, and entity labels. This comparison estimates the penalty attributable to parsing PDB fixed-column syntax rather than spatial reasoning itself.

Use the same three-decimal coordinate precision for both representations.

### **Input budget and cropping**

Set a versioned token budget in the dataset configuration; use 64,000 reference-tokenizer tokens per automatic prompt and 96,000 per mechanistic prompt as initial defaults. Record actual token counts for every evaluated model.

* Do not crop P01, P02, S05, or any question whose answer is defined over a complete chain or structure.  
* For local questions, a crop may be used only when the prompt explicitly says it is a local structure excerpt and the crop contains every atom needed to determine the gold answer.  
* Paired representations of an instance must contain the same retained atom set.  
* Paired states must use corresponding crop rules.  
* Reject an instance rather than truncate structure text at evaluation time.

### **Rotation variants**

For approximately 20% of semantic instances, create a second variant using a different proper random rotation. This measures rotation invariance.

For two-state questions, align the states first and then apply the same random transformation to both. Independently rotating paired states is a separate, harder alignment task and is out of scope for V1.

### **Mechanistic context-only controls**

For at least a subset of mechanistic episodes, render an additional context-only variant with the experimental setup but no coordinates. This estimates how much performance comes from biological prior knowledge or recognition rather than use of the supplied structure.

## **7\. Prompt and answer conventions**

### **System prompt**

Create one versioned system prompt that establishes:

```
You will be given one or more molecular structures and a question about them.
Answer using only the information supplied in the prompt. Do not use tools or
external resources.

Protein residues are identified as <chain>:<one-letter amino-acid code><author
residue number>. For example, A:V22 is valine 22 in chain A. When asked for a
residue, use exactly this format. When asked for a list, return a comma-separated
list. Do not include additional residues.

Place the machine-readable answer after FINAL: using the format requested by
the question. You may reason before the final answer, but only the FINAL field
will be scored.
```

Add task-specific formatting instructions to the user prompt.

### **Canonical answer formats**

```
Single residue:       FINAL: A:V22
Residue list:         FINAL: A:D18, A:E21, B:Y44
Atom:                 FINAL: A:H57:NE2
Residue pair:         FINAL: A:C24--B:C81
Pair list:            FINAL: A:C24--A:C79, B:C15--B:C66
Category:             FINAL: helix
Boolean:              FINAL: yes
Numeric distance:     FINAL: 3.42
Multiple choice:      FINAL: B
Ordered contact path: FINAL: A:R10 -> A:F42 -> B:E77
```

The scorer should ignore harmless whitespace and case differences where appropriate, canonicalize unordered sets and unordered residue pairs, and reject extra unrequested items.

### **Mechanistic multi-field answers**

```
FINAL
changed_residues: A:W422
gained_interactions: A:W422--A:Y177, A:W422--L:L2401
mechanism: A
```

Score each field separately.

## **8\. Automatically generated question families**

`AAA`, `BBB`, and `CCC` below represent chain-qualified residue identifiers. `ATOM1` and `ATOM2` represent atom names.

Every generator must use Appendix A, enforce ambiguity margins, produce hidden geometric evidence, and reject singular questions with multiple correct answers.

### **Required V1 scope and allocation**

The following 19 types are required. The target counts sum to 91 automatically generated instances. A mechanistic episode in Section 11 is one additional composite instance, even though it has multiple scored fields; the six episodes therefore bring the target to 97\.

| ID | Level | Required question type | Answer schema | Target |
| ----- | ----- | ----- | ----- | ----: |
| P01 | Parsing | List all visible chain IDs. | unordered string set | 4 |
| P02 | Parsing | Count protein residues in a specified chain. | integer | 4 |
| P03 | Parsing | Report the displayed coordinates of a specified atom. | numeric triple | 4 |
| G01 | Geometry | Calculate the distance between two specified atoms. | distance | 5 |
| G02 | Geometry | Identify the nearest noncovalently bonded protein atom to a specified protein atom. | atom | 5 |
| G03 | Geometry | Identify the closest residue among a supplied candidate list. | residue | 5 |
| G04 | Geometry | Identify the uniquely most severe clashing residue pair. | residue pair | 4 |
| S01 | Local structure | Identify the unique salt-bridge partner of a specified residue. | residue | 5 |
| S02 | Local structure | Identify the single phosphorylated protein residue. | residue | 4 |
| S03 | Local structure | Classify a specified residue as buried or solvent-exposed. | category | 5 |
| S04 | Local structure | Classify secondary structure at a specified residue. | category | 5 |
| S05 | Global structure | Classify a specified chain as predominantly alpha, predominantly beta, or mixed. | category | 5 |
| S06 | Local structure | List all protein residues within 4 Å of a specified ligand. | residue set | 5 |
| S07 | Local structure | List all protein residues directly coordinating a specified metal. | residue set | 5 |
| S08 | Local structure | Identify the disulfide-bonded partner of a specified cysteine. | residue | 5 |

For P03, request `FINAL: x, y, z` and score each component within 0.001 Å, because the task is transcription rather than distance calculation. For T01, request:

```
FINAL
gained: A:R10--B:E77, A:Y15--L:L401
lost: A:D22--A:K91
```

Each generated instance must use a different source protein within its type where feasible. No protein may contribute more than six automatic semantic instances to the final set. Use short structures for parsing tasks, validated biological assemblies for I01, and experimentally observed matched structures for T01. Only mapped residues with the same amino-acid identity are eligible for T01.

### **Extension backlog, not required for V1**

Keep generator interfaces extensible for the following question types, but do not implement them until the required V1 suite passes validation:

* Polymer-content classification.  
* Complete disulfide-pair lists.  
* Proline cis/trans state.  
* 3-10 helix identification.  
* Metal-coordinating atom identity.  
* Closest pair or salt bridge across a protein-protein interface.  
* Residues contacting both an interface and a ligand.  
* Unique shortest contact paths and graph-theoretic articulation residues.  
* Two-state rotamer, salt-bridge, interface, displacement, secondary-structure, burial, and contact-path changes beyond T01.  
* Generic hydrogen bonds or loosely defined hydrophobic interactions.

Aromatic packing may be used in curated mechanistic episodes only when the ring definition and ligand bond graph are available.

## **9\. Protein selection and dataset composition**

Select approximately 30-50 proteins so that individual proteins do not dominate the benchmark.

Balance the dataset across:

* PDB and AFDB where appropriate.  
* Protein size and input-token length.  
* Alpha, beta, and mixed folds.  
* Single-chain and multichain structures.  
* Soluble and membrane proteins.  
* Apo and ligand-bound structures.  
* Experimental methods and resolutions for PDB entries.  
* Release dates.

AFDB structures may be used for intrinsic geometry, burial, secondary structure, rotamers, and similar single-chain tasks. Do not use AFDB for experimental ligand, modification, metal, or biological-assembly questions. Require high pLDDT around queried AFDB residues, but remove or zero the model-visible pLDDT values after selection.

Record:

* Structure release date.  
* Associated publication date when available.  
* Experimental method and nominal resolution.  
* Sequence cluster and fold classification when available.  
* Source protein and paper grouping for bootstrap analysis.  
* Atom count and token count for each rendered representation.

Release date is a covariate, not a guarantee of freedom from contamination.

## **11\. Manually curated mechanistic understanding**

Mechanistic questions test whether a model can connect a local structural change to a larger conformational or functional effect. Render each episode as one prompt with multiple structured answer fields.

Each episode has three scored levels:

1. **Structural observation:** which residue, contact, or element changed?  
2. **Structural integration:** what interaction or packing arrangement resulted?  
3. **Mechanistic interpretation:** which controlled causal explanation is best supported?

The first two fields are deterministically scored. The third is multiple choice. A free-text explanation may be collected for qualitative analysis but does not contribute to the primary score.

### **Shared mechanistic processing requirements**

For each episode:

1. Download the specified structures.  
2. Identify the appropriate chains, ligands, and best-resolved copy.  
3. Map paper residue numbers to PDB author chain and residue identifiers.  
4. Align the states on a conserved core that excludes the feature being tested.  
5. Apply a shared random rigid-body transformation.  
6. Anonymize structures and ligands.  
7. Retain all task-relevant HETATMs and interacting chains.  
8. Produce equivalent minimal-PDB and normalized-coordinate variants.  
9. Use the same local crop in both representations if cropping is required.  
10. Validate all paper-derived claims against the final displayed coordinates.  
11. Store mappings, alignment core, state labels, crops, and continuous measurements privately.

### **Episode 1: M2 receptor positive allosteric modulation**

**Structures**

* [4MQS](https://www.rcsb.org/structure/4MQS): orthosteric agonist only.  
* [4MQT](https://www.rcsb.org/structure/4MQT): orthosteric agonist plus positive allosteric modulator.

**Model-visible context**

> Both structures contain the same receptor and orthosteric agonist. One structure additionally contains an allosteric ligand, L2. Binding experiments show that L2 increases the receptor's affinity for the orthosteric agonist. Compare the extracellular ligand-binding vestibules.

**Questions**

1. Which receptor residue undergoes the most prominent side-chain rotamer change among residues contacting L2?  
2. What new local packing arrangement is enabled? Report the changed residue and its principal protein and ligand partners.  
3. Which explanation is best supported?

**Mechanism options**

* **A.** L2 stabilizes the agonist-bound extracellular conformation by creating additional packing in the vestibule.  
* **B.** L2 competes with and ejects the orthosteric agonist.  
* **C.** L2 covalently modifies an intracellular residue.  
* **D.** L2 changes only the global coordinate orientation.

**Expected result**

* Changed residue: Trp422.  
* New arrangement: Trp422 packs between L2 and Tyr177.  
* Mechanism: A.

Regenerate all chain-qualified labels from the processed files.

### **Episode 2: CB1 aromatic twin toggle switch**

**Structures**

* [5TGZ](https://www.rcsb.org/structure/5TGZ): antagonist-bound inactive state.  
* [5XRA](https://www.rcsb.org/structure/5XRA): agonist-bound state.  
* Optional robustness replicate: [5XR8](https://www.rcsb.org/structure/5XR8).

**Model-visible context**

> Structure 1 contains a receptor bound to an antagonist that stabilizes an inactive state. Structure 2 contains the same receptor bound to an agonist. Compare the ligand-binding pockets and coupled intracellular-facing conformations.

**Questions**

1. Which pair of aromatic residues undergoes the clearest coordinated rearrangement?  
2. How does their mutual packing differ between states?  
3. Which explanation is best supported?

**Mechanism options**

* **A.** Agonist binding reorganizes an aromatic toggle pair, coupling ligand-pocket contraction to an activation-compatible intracellular surface.  
* **B.** Activation results from breaking a disulfide bond.  
* **C.** The structures differ only by rigid-body rotation.  
* **D.** The antagonist activates the receptor through a covalent aromatic adduct.

**Expected result**

* Changed residues: Phe200 and Trp356.  
* Mechanism: A.

Validate side-chain dihedrals, ring distances, missing atoms, and alignment sensitivity.

### **Episode 3: A2A receptor activation by G-protein engagement**

**Structures**

* [3QAK](https://www.rcsb.org/structure/3QAK): agonist-bound active-intermediate receptor.  
* [5G53](https://www.rcsb.org/structure/5G53): receptor bound to agonist and mini-Gs.

Use the best-resolved receptor-mini-Gs complex in 5G53; the source paper analyzes the A/C complex.

**Model-visible context**

> Both structures contain an agonist-bound receptor. One is an active-intermediate state without a G protein; the other is a G-protein-bound active state. Focus on the cytoplasmic half of the receptor.

The deposited structures contain different agonists. Restrict scoring to the cytoplasmic region.

**Questions**

1. Which three conserved receptor residues undergo the important side-chain rearrangements?  
2. What major backbone movement accompanies them?  
3. Which receptor-G-protein contact is enabled?  
4. Which explanation is best supported?

**Mechanism options**

* **A.** G-protein engagement stabilizes outward movement of helix 6, repacking conserved side chains and creating a receptor-G-protein interface.  
* **B.** It restructures only the extracellular agonist pocket.  
* **C.** The G protein replaces the orthosteric ligand.  
* **D.** Binding causes no receptor conformational change.

**Expected result**

* Changed residues: Arg102, Tyr197, and Tyr288.  
* Backbone movement: approximately 14 Å outward displacement of the cytoplasmic end of helix 6\.  
* New interaction: Arg102 packs against mini-Gs Tyr391.  
* Mechanism: A.

Verify sequence correspondence and exclude unmatched engineered regions.

### **Episode 4: Beta2AR-Gs interface exchange**

**Structures**

* [6E67](https://www.rcsb.org/structure/6E67): receptor bound to a peptide derived from the C-terminal alpha5 helix of G-alpha-s.  
* [3SN6](https://www.rcsb.org/structure/3SN6): mature nucleotide-free receptor-Gs complex.

Do not use 6EG8 as the mature receptor-bound comparator; it is receptor-free GDP-bound Gs.

**Model-visible context**

> Structure 1 represents an initial receptor interaction with the C-terminal alpha5 region of a G protein. Structure 2 represents the mature nucleotide-free receptor-G-protein complex. Compare which face of alpha5 contacts the receptor.

**Questions**

1. Which G-alpha-s residues make the characteristic initial contacts?  
2. Which different residues become receptor-facing in the mature complex?  
3. What alpha5 orientation change accompanies the exchange?  
4. Which explanation is best supported?

**Mechanism options**

* **A.** Alpha5 reorients during maturation, replacing the initial contacts with another receptor-facing surface and coupling engagement to G-protein rearrangement.  
* **B.** The alpha5 interface is identical in both states.  
* **C.** G-beta replaces alpha5 at the interface.  
* **D.** The states differ only by coordinate orientation.

**Expected result**

* Initial residues: Arg389 and Glu392.  
* Mature residues: His387 and Tyr391.  
* Initial receptor contacts include Arg131-Glu392 and Tyr141/Thr68-Arg389.  
* Mechanism: A.

This is the most technically difficult case. Map the fused peptide and full G-alpha-s by sequence rather than assuming matching PDB identifiers.

### **Episode 5: TRPV1 Tyr511 rotamer change after lipid displacement**

**Structures**

* [5IRZ](https://www.rcsb.org/structure/5IRZ): unliganded channel in a lipid nanodisc.  
* [5IRX](https://www.rcsb.org/structure/5IRX): channel bound to resiniferatoxin and DkTx.

Select one well-resolved protomer. Preserve the resident lipid in 5IRZ and resiniferatoxin in 5IRX.

**Model-visible context**

> Structure 1 is an unliganded ion channel in a lipid environment. Structure 2 contains an activating ligand in a transmembrane pocket. Experiments show that occupancy of this pocket promotes opening. Compare the local pocket geometry.

**Questions**

1. Which aromatic residue undergoes the clearest ligand-associated rotamer change?  
2. What occupies the relevant space in the unliganded structure?  
3. What interaction becomes possible after displacement?  
4. Which explanation is best supported?

**Mechanism options**

* **A.** The activating ligand displaces a resident lipid, allowing an aromatic side chain to reorient and contact the ligand.  
* **B.** The activating ligand preserves the unliganded lipid pose and prevents rearrangement.  
* **C.** Activation occurs by cleavage of the aromatic residue.  
* **D.** The ligand binds only to the extracellular toxin site.

**Expected result**

* Changed residue: Tyr511.  
* Displaced component: a resident phosphatidylinositol-like lipid acyl chain.  
* Gained interaction: Tyr511-ligand contact.  
* Mechanism: A.

Score hydrogen-bond identity only if ligand donor/acceptor chemistry is explicitly represented.

### **Episode 6: TRPV1 Arg557-Glu570 gate coupling**

**Structures**

* [5IRZ](https://www.rcsb.org/structure/5IRZ): unliganded state.  
* [5IRX](https://www.rcsb.org/structure/5IRX): agonist-bound state.  
* Optional antagonist state: [5IS0](https://www.rcsb.org/structure/5IS0).

This episode may reuse processed structures from Episode 5, but aggregate and bootstrap by protein or paper so the two TRPV1 cases do not receive independent full weight.

**Model-visible context**

> The structures show unliganded and ligand-bound states of the same ion channel. One ligand is an agonist that promotes opening. Identify the interaction that most directly couples the ligand pocket to movement of the intracellular gate.

**Questions**

1. Which oppositely charged pair forms a new close interaction in the agonist-bound state?  
2. Is the interaction within one protomer or between protomers?  
3. What local backbone element moves with it?  
4. Which explanation is best supported?

**Mechanism options**

* **A.** A new Arg-Glu interaction couples pocket rearrangement to displacement of the S4-S5 linker and lower-gate opening.  
* **B.** Opening results from breaking an extracellular disulfide.  
* **C.** The charged pair is unchanged and unrelated to gating.  
* **D.** Only the antagonist forms the activating pair.

**Expected result**

* Gained interaction: Arg557-Glu570 within one protomer.  
* Coupled element: S4-S5 linker displacement away from the pore axis.  
* Mechanism: A.

Retain minimum charged-atom distances in hidden metadata.

## **12\. Deterministic scoring**

Do not use an LLM judge for the primary benchmark.

* Single residue, atom, category, boolean, or multiple choice: exact accuracy after canonical parsing.  
* Numeric coordinate triple: all three components must fall within the task-specific tolerance.  
* Residue or interaction set: set F1 as primary; exact-set accuracy as a strict secondary metric.  
* Two-state gained/lost answer: score the two interaction sets separately, then average them.  
* Ordered path: exact ordered-node accuracy, with an optional per-position score.  
* Numeric answer: absolute-tolerance accuracy.  
* Mechanistic episode: score each structured field separately and optionally compute their mean.  
* Malformed, refused, or truncated answer: score zero and report the failure category separately.

Report macro-averages across question families. Also report micro-averages, but do not let families with longer answer lists dominate the headline score.

## **13\. Run-to-run variability and statistical analysis**

Keep three sources of variation separate:

1. **Benchmark composition:** quantify using bootstrap resampling clustered by protein or paper.  
2. **Model stochasticity:** repeat identical prompts.  
3. **Representation sensitivity:** compare matched PDB, normalized-coordinate, context-only, and rotation variants.

### **Recommended final protocol**

* Three independent completions for every rendered prompt.  
* Five to ten completions on a stratified 20-instance reliability subset.  
* Mean score across completions as the primary model score; do not use pass@k.  
* Pairwise exact agreement for scalar/categorical answers.  
* Pairwise Jaccard agreement for set answers.  
* Hierarchical bootstrap confidence intervals clustered by protein or source paper.  
* Paired confidence intervals for PDB-versus-normalized-coordinate and rotation differences.

Store exact model identity, date, reasoning effort, sampling configuration, token limits, and raw responses.

# **Appendix A: Operational definitions**

Keep these definitions in a versioned configuration file. Every instance records the definition version used to generate it.

## **A.1 Structure and model selection**

* Use a curator-approved biological assembly for interface and oligomer questions.  
* Do not automatically equate the deposited asymmetric unit with the biological assembly.  
* Use a single coordinate model. Exclude NMR ensembles in V1.  
* AFDB structures are single-chain predicted structures and are eligible only for appropriate intrinsic-structure tasks.  
* Compute gold answers after filtering, alignment, rotation, cropping, and coordinate rounding.

## **A.2 Minimal structure processing**

1. Remove PDB identifiers, titles, annotations, publication references, secondary-structure records, `LINK`, `SSBOND`, `ANISOU`, and unrelated metadata.  
2. Remove hydrogens, deuteriums, and waters.  
3. Remove crystallization additives, detergents, and buffers unless selected as task-relevant entities.  
4. Retain protein/nucleic-acid `ATOM` records and curator-selected `HETATM` records.  
5. Retain `TER` and `END`.  
6. Retain task-relevant ligands, cofactors, modifications, metals, and lipids.  
7. Renumber atom serials.  
8. Set occupancy uniformly after alternate-location resolution.  
9. Zero B-factors. For AFDB, this removes model-visible pLDDT.  
10. Apply a proper rotation with determinant \+1, never a reflection.  
11. Write coordinates to three decimal places.  
12. Verify that every atom required by the oracle remains present.

Make the rigid transform reproducible from `rotation_seed`. Use a versioned random-number algorithm, center the retained coordinates, generate a uniformly distributed unit quaternion, and convert it to a proper rotation matrix. For paired structures, calculate one centroid over the union of both aligned atom sets and apply the same matrix and translation to both. Store the matrix and translation, assert that the determinant is \+1 within numerical tolerance, and reject a rendering if any transformed value overflows the PDB coordinate fields.

Exclude structures or queried sites with insertion codes, ambiguous chain IDs, microheterogeneity, or missing required atoms in V1.

## **A.3 Alternate locations and occupancy**

1. Treat blank-altloc atoms as shared.  
2. For each residue, choose the nonblank conformer with the highest summed occupancy over side-chain heavy atoms.  
3. Never select alternate locations independently per atom.  
4. Break occupancy ties alphabetically by altloc identifier.  
5. Exclude zero-occupancy atoms.  
6. Reject a queried residue if the chosen conformer lacks a required atom.

## **A.4 Coordinate precision and distance**

* Coordinates are in Å.  
* PDB and normalized-table variants use three decimals.  
* Distances are Euclidean distances computed from displayed coordinates.  
* A cutoff is inclusive; within 4 Å means distance \<= 4.000 Å.  
* Unless overridden, require negative examples to lie at least 0.20 Å beyond a cutoff.  
* For nearest-neighbor questions, require the closest answer to be at least 0.25 Å closer than the runner-up.  
* Score numeric distances with absolute error \<= 0.02 Å.

## **A.5 Chains, residues, atoms, and entities**

Protein residues use:

```
<author chain>:<one-letter amino-acid code><author residue number>
```

Examples: `A:V22`, `B:Y104`.

* Sequence adjacency is based on polymer order, not residue-number subtraction.  
* Modified residues use the parent amino-acid letter.  
* Atom-specific identifiers append the atom name: `A:H57:NE2`.  
* Non-protein entities use stable model-visible labels plus chain and author residue number, such as `L:L1401` or `M:ZN501`.  
* A protein residue is counted when it is part of the polymer and has at least one retained atom.  
* Chain IDs are the unique chain IDs visible in the rendered structure.

## **A.6 Heavy atoms**

A heavy atom is any non-hydrogen atom.

* Hydrogens and deuteriums are ignored.  
* Waters are excluded from generic contacts.  
* Water-mediated interactions are not direct interactions.  
* Protein, nucleic acid, ligand, ion, and water entity types are stored separately.

## **A.7 Polymer-content class**

Classify the supplied structure from retained polymer residues as:

* `protein`: protein polymer only.  
* `DNA`: DNA polymer only.  
* `RNA`: RNA polymer only.  
* `mixed`: more than one of protein, DNA, and RNA.

Nonpolymer ligands and ions do not affect this class.

## **A.8 Covalent topology and nearest nonbonded atom**

Construct covalent topology from a versioned chemical-component dictionary and standard polymer bonds.

For nearest-nonbonded-atom questions:

* Exclude the query atom itself.  
* Exclude atoms connected by one covalent bond.  
* Exclude atoms connected by two covalent bonds.  
* Restrict both the query and answer to protein heavy atoms in V1.  
* Restrict V1 questions to standard residues with unambiguous topology.  
* Treat identified disulfides as covalent bonds.

## **A.9 Generic residue-residue contact**

Two protein residues contact when any heavy-atom pair has distance \<= 4.0 Å.

* Exclude self-contact.  
* For generic intrachain contact graphs, exclude pairs separated by zero, one, or two polymer positions unless local backbone packing is explicitly requested.  
* Do not apply this exclusion to interchain contacts.  
* Store the minimum distance and atom pair.

## **A.10 Protein-ligand contact**

A protein residue contacts a specified ligand when any protein-ligand heavy-atom pair has distance \<= 4.0 Å.

* The curator or generator defines the complete ligand atom set.  
* Exclude waters, buffers, detergents, and crystallization additives unless explicitly selected.  
* Treat monatomic metals under metal coordination.  
* Store the minimum-distance atom pair.

## **A.11 Salt bridge**

A salt bridge exists when a listed positive atom lies within 4.0 Å of a listed negative atom.

Positive atoms:

* Lys `NZ`  
* Arg `NE`, `NH1`, `NH2`

Negative atoms:

* Asp `OD1`, `OD2`  
* Glu `OE1`, `OE2`

Exclude histidine, terminal groups, and unsupported modified residues in V1. Store the minimum qualifying distance. Singular questions require exactly one partner.

## **A.12 Phosphorylated residue**

Recognize only covalent modified-residue component codes:

* `SEP`: phosphoserine  
* `TPO`: phosphothreonine  
* `PTR`: phosphotyrosine

Do not infer phosphorylation from a nearby free phosphate ion.

## **A.13 Solvent exposure and burial**

Use the Shrake-Rupley algorithm with:

* Probe radius 1.4 Å.  
* A fixed versioned atomic-radii set.  
* Waters excluded.  
* All retained assembly atoms included as occluding atoms.  
* Relative ASA calculated using Tien et al. 2013 residue-specific maximum ASA values.

Classify:

* `buried`: rASA \<= 0.20.  
* `solvent-exposed`: rASA \>= 0.40.  
* intermediate: otherwise.

Do not generate binary questions from intermediate residues. Store absolute SASA and rASA. Include both charged and hydrophobic queried residues.

## **A.14 Per-residue secondary structure**

Assign DSSP on the processed coordinates and map:

* `helix`: `H`, `G`, or `I`.  
* `strand`: `E` or `B`.  
* `coil`: `T`, `S`, blank, or other.

Reject residues with missing backbone atoms, failed assignments, or proximity to a crop boundary.

Parallel-versus-antiparallel beta-sheet classification is deferred from V1 unless a separately tested bridge-orientation implementation is added.

## **A.15 3-10 helix**

A residue is in a 3-10 helix when DSSP assigns `G`.

For list questions:

* Require a contiguous run of at least three `G` residues in polymer order.  
* Ask about a specified chain.  
* Reject runs truncated by missing coordinates or a crop boundary.

## **A.16 Overall alpha/beta class**

Over residues with valid DSSP assignments:

```
helix_fraction = fraction in H, G, or I
beta_fraction  = fraction in E or B
```

Classify:

* `predominantly alpha helical`: helix fraction \>= 0.35 and greater than twice beta fraction.  
* `predominantly beta sheet`: beta fraction \>= 0.25 and greater than twice helix fraction.  
* `mixed alpha/beta`: both fractions \>= 0.15 and their ratio is between 0.5 and 2.0.

Reject chains or domains satisfying none of these definitions.

## **A.17 Proline cis/trans state**

For proline residue `i`, calculate omega using:

```
CA(i-1)-C(i-1)-N(i)-CA(i)
```

Normalize omega to `[-180 degrees, 180 degrees)`.

* `cis`: absolute omega \<= 30 degrees.  
* `trans`: `abs(abs(omega) - 180 degrees) <= 30 degrees`.  
* otherwise ambiguous; reject.

Require all four atoms and the preceding polymer residue. Include at least one accepted cis-proline instance.

## **A.18 Severe nonbonded clash**

Use a fixed versioned van der Waals radius table. A heavy-atom pair clashes when:

```
distance < radius(atom 1) + radius(atom 2) - 0.40 Å
```

Exclude:

* Atoms separated by one or two covalent bonds.  
* Expected metal-coordination contacts.  
* The two sulfurs of a disulfide.  
* Alternate conformers already resolved away.

A residue pair clashes if it contains at least one clashing atom pair. Generate only instances with one uniquely most severe residue-pair clash, separated from the runner-up by at least 0.20 Å of overlap.

## **A.19 Metal ion and direct coordination**

Eligible retained monatomic metals:

```
ZN, MG, MN, FE, CU, CO, NI, CA
```

A protein N, O, or S atom directly coordinates the metal when its distance is at most:

| Metal | Maximum donor distance |
| :---- | ----: |
| Mg | 2.5 Å |
| Zn | 2.6 Å |
| Cu | 2.6 Å |
| Ni | 2.6 Å |
| Co | 2.7 Å |
| Fe | 2.8 Å |
| Mn | 2.9 Å |
| Ca | 3.1 Å |

*   
  Backbone and side-chain donors are allowed.  
* Carbon is never a donor.  
* Water-mediated contacts are not direct protein coordination.  
* Protein coordination number counts donor atoms, not residues or waters.  
* Require positive distances at least 0.15 Å inside the cutoff and the closest excluded protein donor at least 0.25 Å outside it.  
* Exclude ambiguous elements, zero occupancy, alternate metal positions, and unstable coordinator sets.

## **A.20 Disulfide bond**

Two cysteine residues form a disulfide when `SG-SG <= 2.30 Å`.

* Both atoms must be present.  
* Do not expose or depend on `SSBOND` records.  
* The bond is intrachain when chain IDs match and interchain otherwise.  
* Negative candidates require `SG-SG >= 3.0 Å`.  
* A cysteine may participate in only one accepted disulfide edge.

## **A.21 χ1 side-chain rotamer**

Calculate chi1 as `N-CA-CB-XG`, using:

* Ser `OG`  
* Thr `OG1`  
* Cys `SG`  
* Val `CG1`  
* Ile `CG1`  
* Other supported standard residues `CG`

Exclude Gly, Ala, Pro, missing atoms, and unsupported noncanonical residues.

Normalize chi1 to `[-180 degrees, 180 degrees)` and classify:

* `g+`: `0 <= chi1 < 120`.  
* `t`: `120 <= chi1 < 180` or `-180 <= chi1 < -120`.  
* `g-`: `-120 <= chi1 < 0`.

Reject residues within 15 degrees of a bin boundary at \-120, 0, or 120 degrees.

## **A.22 χ1 rotamer change**

A mapped residue changes chi1 state when:

1. Amino-acid identity matches between structures.  
2. Chi1 exists in both.  
3. The states occupy different bins.  
4. Minimum circular angular difference is at least 60 degrees.  
5. Both angles are at least 15 degrees from a boundary.

For a rotamer change without backbone movement, additionally require aligned C-alpha displacement \<= 1.0 Å.

## **A.23 Protein-protein interface contact**

For specified protein chains, an interface edge is a cross-chain generic contact with minimum heavy-atom distance \<= 4.0 Å.

* Use a validated biological assembly.  
* Exclude crystal symmetry contacts unless explicitly requested.  
* Store the minimum-distance atom pair.  
* A closest-pair question requires a 0.25 Å margin.  
* An interchain salt bridge must satisfy both definitions.

## **A.24 Residue-contact graph**

Construct an undirected graph:

* Protein residues are nodes.  
* Selected ligands and metals may be additional nodes.  
* Protein-protein edges use the generic contact definition.  
* Intrachain pairs within two polymer positions are excluded.  
* Interchain contacts are retained.  
* Protein-ligand edges use the ligand-contact definition.  
* Protein-metal edges use direct coordination.

Use an unweighted graph for V1 shortest paths. Preserve minimum distances as edge metadata.

## **A.25 Bridging and articulation residues**

A **direct bridging residue** contacts both specified anchors or groups.

* It cannot be one of the anchors unless explicitly allowed.  
* The anchors should not directly contact each other.  
* Singular questions require a unique bridge.

An **articulation residue** is a residue node whose removal disconnects two specified anchors in the defined graph or local induced subgraph. Prompts must explicitly describe node removal and must have a unique answer.

## **A.26 Shortest contact path**

* Path length is the number of graph edges.  
* Initially require one unique shortest path.  
* Limit V1 paths to at most three edges.  
* Return nodes in order from the first anchor to the second.

## **A.27 Two-state residue mapping and structural alignment**

1. Map polymer residues by sequence alignment.  
2. Define a conserved C-alpha alignment core in hidden metadata.  
3. Exclude the queried flexible region from the core.  
4. Perform least-squares rigid-body superposition.  
5. Optionally remove core pairs with residuals \> 2.0 Å and refit once.  
6. Apply one shared random transform after alignment.  
7. Round and render coordinates.  
8. Recompute comparison labels from rendered coordinates.

## **A.28 Gained and lost contacts**

For a mapped residue pair:

* `gained in Structure 2`: distance \<= 4.0 Å in Structure 2 and \>= 4.5 Å in Structure 1\.  
* `lost in Structure 2`: distance \<= 4.0 Å in Structure 1 and \>= 4.5 Å in Structure 2\.  
* `retained contact`: distance \<= 4.0 Å in both.  
* `retained noncontact`: distance \>= 4.5 Å in both.  
* otherwise ambiguous; reject.

Apply the same hysteresis to protein-ligand and interface contacts.

For salt bridges, use the relevant charged-atom distances with the same 4.0/4.5 Å thresholds.

## **A.29 Backbone displacement**

After alignment, use mapped C-alpha distance:

* approximately unchanged: \<= 1.0 Å.  
* substantially displaced: \>= 3.0 Å.  
* intermediate: reject for binary questions.

For largest-displacement questions, require the winner to exceed the runner-up by at least 1.0 Å.

## **A.30 Secondary-structure change**

A mapped residue changes class when its three-state DSSP class differs between structures. Reject missing assignments and residues adjacent to missing-coordinate or crop boundaries.

## **A.31 Burial upon complex formation**

1. Compute rASA for the isolated specified chain.  
2. Compute rASA in the supplied complex.  
3. Require an rASA decrease of at least 0.20.  
4. Require complex-state rASA \<= 0.20.

## **A.32 Aromatic packing**

When aromatic packing is scored, identify rings from a versioned residue/ligand bond dictionary.

Two aromatic groups pack when:

* Ring-centroid distance \<= 6.0 Å.  
* Minimum inter-ring heavy-atom distance \<= 4.5 Å.

Store ring-plane angles, but do not require parallel-versus-edge classification in V1. Do not infer anonymous-ligand aromaticity from coordinates without bond-order information.

## **A.33 Hydrogen bonds**

Hydrogen-bond questions are deferred from the V1 automatic task set.

If required for a curated mechanistic claim, use:

* Donor and acceptor identities from a versioned chemical dictionary.  
* Donor-acceptor distance \<= 3.5 Å.  
* Donor-base-donor-acceptor angle \>= 90 degrees when bonded heavy-atom geometry is available.

Do not score anonymous-ligand hydrogen bonds without ligand bond orders, formal charges, and donor/acceptor assignments.

## **A.34 Rejection criteria**

Reject or require manual review when:

* Required atoms are missing.  
* Relevant alternate conformations remain unresolved.  
* A metal, ligand, or modification has ambiguous occupancy.  
* State mapping is uncertain.  
* The biological assembly is uncertain.  
* Crystal packing could be confused with the biological interface.  
* Cropping removes atoms needed by the oracle.  
* A value lies inside an ambiguity margin.  
* A singular prompt has multiple valid answers.  
* Local structure quality is inadequate for the claimed side-chain geometry.

Every candidate should retain a machine-readable record of passed and failed criteria.
