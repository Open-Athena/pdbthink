Rerunning Qwen’s capped attempts.

The original run answered 56/88 structure-interpretation questions exactly correctly, with 17 answers stopped at 32,768 output tokens. Original results remain available.

Each native-context retry gets 262,144 minus its exact prompt-token count for reasoning and output. Attempts that exhaust that capacity are retried separately with the publisher’s 1,010,000-token YaRN configuration. The extension changes positional scaling and is reported as a separate condition. Prompts, checkpoint, sampling parameters and attempt seeds are preserved.

Every new request explicitly disables tool calls. The runner verifies server tokenisation, retains raw provider responses, audits tool events and rejects output clamps below the requested budget. Uncapped historical answers retained in a combined recovery panel keep their original tool-control status.
